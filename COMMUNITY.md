# Community participation

**Try the demo. Challenge the assumptions. Improve the controls.**

This independent project models fictional workplace budgets, vendor decisions, staffing, events and forecast accuracy. No association with any actual business is implied.

## Ways to participate
- Try a budget challenge and describe which management trade-off you would choose.
- Check the forecast model against a carefully constructed synthetic edge case.
- Suggest new KPIs, accessibility fixes or reporting improvements.
- Contribute a pull request with a reproducible test.

Start with an issue: https://github.com/StiliIlist/workplace-operations-command-center/issues

Be professional and constructive. Do not post sensitive information, real employee names, contracts, invoices or customer records.
