# Contributing

Welcome to Workplace Operations Lab, an independent fictional portfolio project. Contributions that improve calculations, accessibility, reporting, simulations and reproducibility are welcome.

## Getting started
1. Open an issue describing the problem or proposed enhancement.
2. Fork the repository and create a focused branch.
3. Change the static `index.html` application and test in a modern browser.
4. Include reproducible test steps and screenshots (with fictional data only).
5. Submit a pull request referencing the issue.

## Priorities
- Verify forecast accuracy metrics and prevent data leakage from future months.
- Improve accessibility and mobile chart usability.
- Add deterministic tests for budget and vendor math.
- Improve print-ready reports and reusable import/export schemas.

## Safety and privacy
No real employee information, confidential vendor quotes or company records. All examples must be synthetic. Do not insert API keys, tokens or credentials. GitHub Issues is public; sanitize screenshots and attached CSVs.

## Feedback
File a GitHub issue describing the expected result, actual result, browser version and steps to reproduce.
